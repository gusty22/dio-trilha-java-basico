# Fundamentos de Java — Trilha DIO

Exercício de introdução à linguagem Java, desenvolvido durante uma trilha de aprendizado.

## Código identificado

A aplicação contém `src/main/java/ContaTerminal.java`, classe de exercício sobre entrada de dados e conceitos fundamentais de programação Java.

## Executar

Abra o projeto em uma IDE Java com suporte ao Maven. Para compilar pelo terminal:

```bash
git clone https://github.com/gusty22/dio-trilha-java-basico.git
cd dio-trilha-java-basico
mvn compile
```

Execute `ContaTerminal` pela IDE para interagir com o exercício.

## Contexto

Repositório educacional que documenta prática de sintaxe, entrada de dados e fundamentos de Java. Não se trata de uma aplicação bancária de produção.
